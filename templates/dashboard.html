📌 ¿Cómo usar el sistema?

  1. Cifrar un mensaje:
    Ingresa a la opción "Cifrar Texto", escribe el contenido que deseas proteger y presiona el botón para cifrar.
  2. Generación de token:
    El sistema generará un token único. Este token es necesario para poder visualizar el mensaje.
  3. Compartir token:
    Copia el token generado y compártelo con la persona que deseas que vea el mensaje.
  4. Uso del token:
    La otra persona deberá ingresar a "Usar Token", pegar el token y podrá visualizar el mensaje.
  5. Importante:
    • El token solo puede utilizarse una vez.
    • El token expira en un máximo de 7 días.
    • Si aparece "Token inválido", ya no es posible acceder al mensaje.
🔐 Seguridad del sistema
  • El cifrado se realiza en el servidor utilizando llaves pública y privada.
  • El sistema registra cada intento de uso del token.
  • Los mensajes eliminados no pueden ser visualizados nuevamente.
